# LocalLauncher

Apple Silicon（Mシリーズ）・macOS 13以降向けのシンプルなアプリランチャー。
このリポジトリは完成アプリの配布専用。ソースは含まない。

## ダウンロード

[最新版のRelease](https://github.com/meic0der/local-launcher-releases/releases/latest)から
`LocalLauncher-mac-arm64.zip`を取得し、展開した`LocalLauncher.app`を自分の
Applicationsフォルダへ配置して開く。Xcode・ビルド・GitHubログインは不要。

Dockのアイコンを右クリックし「オプション → Dockに追加」で固定できる。
ログイン時の起動はmacOSの「システム設定 → 一般 → ログイン項目」で追加する。

## 機能

- アプリ検索・起動、Command Spaceで呼び出し
- アプリごとのキー操作を記録して直接起動
- 四則演算・括弧・小数の電卓。Enterで結果をコピー
- 選択してEnterを押したときだけWeb検索
- ダーク基調のシンプルな画面
- メニューの「アップデートを確認…」から署名付き更新

Command SpaceがSpotlight等と競合する場合は、利用者がそちらの設定を変更する。
登録済みショートカットはアプリ更新後も同じMac内に保持する。Mac間の設定同期はない。
旧版に更新メニューがない場合や、v0.2.0が起動を阻止された場合は、最新版のZIPから入れ替える。

## データと更新

検索履歴・クリップボード履歴・利用統計を収集しない。
入力中の外部送信なし。Web検索時は選んだ検索語を検索先へ送信する。
更新確認時はGitHubへ接続し、更新フィードと必要なZIPを取得する。
設定内容・検索語を更新配信先へ送らない。自動チェック・自動ダウンロードは無効。

更新はSparkleを使用し、ZIPのEd25519署名を検証する。第三者ライセンス通知はアプリ内に同梱。
v0.3.0以降はApple Developer ID署名・Apple公証済み（公証チケットをアプリへ添付）。
署名には開発者の登録氏名が含まれる。v0.2.0以前はアドホック署名でApple公証なし。
会社での利用可否は管理者判断。Gatekeeper・MDMが拒否する場合、保護設定を解除せず管理者へ相談する。

会社Macでの動作と、Sparkle画面を操作した旧版から新版への更新は未検証。
